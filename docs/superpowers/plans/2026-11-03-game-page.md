# Stage 3 Game Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page per game at `/game/<titleId>` (hero, fact tiles, description, screenshots, updates, DLC, files, admin download and metadata edit) replacing the Library's metadata modal.

**Architecture:** An explicit Flask route renders `game.html` with the same access and role values as the Library (shared helper). `static/js/game.js` loads the game with one `title(titleId:)` GraphQL query and renders everything client-side. Helpers both pages need move to `static/js/library-common.js`.

**Tech Stack:** Flask/Jinja, jQuery, Bootstrap 5.3, Strawberry GraphQL, pytest.

**Spec:** `docs/superpowers/specs/2026-11-03-game-page-design.md`

## Global Constraints

- `beta/` only, branch `beta`, never push, version unchanged; CHANGELOG under `## [Unreleased - beta]`.
- Server: only the new route and a shared role helper; no GraphQL/schema changes.
- One bare inline `<script>` per page; logic in `static/js/*.js`; strings in `app/i18n.py` (`en` + `es` voseo).
- Tokens only for colors; stage 1 components.
- Catalogue text reaches the DOM through `.text()` / attributes only.
- Tests from `beta/`, Python 3.13 venv, `PYTHONUTF8=1`, `tests/...` paths.

## Review Focus

1. A private shop and an anonymous visitor: `/game/<id>` redirects to login like `/`; a shopper sees no admin controls and the query returns no `files`. Pinned in Tasks 2-3.
2. An id that is lowercase, too short, not hex, or valid but unknown: lowercase works; the others show not-found (404 for malformed). Pinned in Task 2/3.
3. A catalogue-only game (not owned): page renders with "Not in your library", no download buttons, DLC all missing. Pinned in Task 3.
4. A DLC card whose parent title id is unknown (unrecognized DLC): links to the DLC's own id page instead of `/game/undefined`. Pinned in Task 6.
5. A failed request shows the error state with Retry. Pinned in Task 3.
